# Тихий список

Небольшой адаптивный To-Do List для тестового задания The Digital.

## Возможности

- Добавление задачи кнопкой или Enter; пробелы без текста не принимаются.
- Отметка выполненной задачи и возврат в работу.
- Удаление задачи.
- Сохранение списка и статусов после обновления страницы через `localStorage`.
- Дополнительно: фильтры, счётчик прогресса, синхронизация между вкладками одного браузера, понятные пустые состояния.
- Текст задач выводится через `textContent`, а не HTML.
- При недоступном хранилище показывается предупреждение; приложение продолжает работать в памяти.

## Запуск

Нужен Python 3. Из корня проекта:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Открыть http://localhost:4173. Если установлен Node.js, можно использовать `npm start`.
Приложению не нужны npm-зависимости или сборка. Открытие HTML через `file://` не рекомендуется: ES-модули требуют HTTP.

## Проверки

Node.js 20+:

```sh
npm test
```

Тесты проверяют чистую логику добавления, переключения, удаления и преобразования сохранённых данных. Для браузерной проверки предусмотрен `tests/browser.cjs`: Playwright и Chromium должны быть доступны в среде. При необходимости поменяйте путь к Chromium. Запускать с работающим локальным сервером:

```sh
node tests/browser.cjs
```

## Структура

- `index.html` — семантическая разметка.
- `styles.css` — адаптивный интерфейс, фокус и reduced-motion.
- `model.js` — чистые функции работы со списком и проверка данных.
- `app.js` — события интерфейса и слой localStorage.
- `tests/` — модульные тесты и браузерный сценарий.

## Ограничения и решения

Простой стек выбран сознательно: для четырёх основных функций не нужны сервер, фреймворк и зависимости. Данные хранятся только в текущем браузере и не передаются на сервер. Очистка данных браузера удалит список; между устройствами синхронизации нет. В конфликте одновременных изменений в разных вкладках действует последнее сохранение. Текст ограничен 300 символами. Пустой список при первом входе намеренный: демонстрационные задачи не выдаются за пользовательские.
